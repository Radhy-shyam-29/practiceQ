Content Badalna

Text, HTML, aur attributes ko read karo aur change karo

📝 textContent vs innerHTML vs innerText Important Diff

let el = document.querySelector("#box"); // textContent — sirf plain text el.textContent = "Hello Duniya!"; // innerHTML — HTML bhi likh sakte ho el.innerHTML = "<strong>Bold Text</strong>"; // innerText — jo dikhta hai wohi (CSS consider karta hai) el.innerText = "Ye visible hai";
⚠️
innerHTML use karte waqt user input kabhi direct mat daalo — XSS attack ho sakti hai! Sirf apna trusted content daalo.

🏷️ Attributes Padhna aur Badalna

let img = document.querySelector("img"); // Attribute padhna img.getAttribute("src"); // "photo.jpg" // Attribute set karna img.setAttribute("src", "new.jpg"); img.setAttribute("alt", "Nai photo"); // Attribute hatana img.removeAttribute("disabled"); // Direct bhi kar sakte ho img.src = "photo.jpg"; img.alt = "Description";

🌊 Event Bubbling — Kya Hota Hai? Advanced

🫧
Bubbling: Jab child element pe click hota hai, toh event uske parent, grandparent — sabko bhi milta hai! Jaise paani mein bubble upar uthta hai.
// DOM structure: // div.outer > div.inner > button // Button click karne pe teeno mein event jaayega! document.querySelector("button").addEventListener("click", (e) => { e.stopPropagation(); // Parent tak mat jaao });

CSS Style Control

JS se styles aur classes manage karo

🎨 Inline Style Dena Easy

let box = document.querySelector("#box"); // Direct style properties box.style.color = "red"; box.style.backgroundColor = "#ff0"; // background-color = camelCase box.style.fontSize = "20px"; box.style.display = "none"; // Chhupao box.style.display = "block"; // Dikhao box.style.transform = "rotate(45deg)";

🏷️ classList — Classes Manage Karo Best Practice

let el = document.querySelector(".card"); // Class add karo el.classList.add("active"); // Class hatao el.classList.remove("active"); // Toggle (hai toh hatao, nahi hai toh add karo) el.classList.toggle("dark-mode"); // Check karo class hai ya nahi el.classList.contains("active"); // true/false // Replace karo el.classList.replace("old-class", "new-class");
💜
Best Practice: Inline style ki jagah CSS classes use karo. classList.toggle() se dark mode jaise features banao!

DOM Traversal

Tree mein navigate karo — parent, child, siblings

🧭 Navigation Properties Core

let el = document.querySelector("#child"); // PARENT: el.parentNode // Direct parent node el.parentElement // Direct parent element el.closest(".card") // Upar jaake pehla .card // CHILDREN: el.children // Saare direct children elements el.childNodes // Saare direct child nodes (text bhi) el.firstElementChild // Pehla child element el.lastElementChild // Aakhri child element // SIBLINGS: el.nextElementSibling // Agla sibling el.previousElementSibling // Pichla sibling

🔁 Saare Children Pe Loop Karo

let ul = document.querySelector("ul"); // forEach (querySelectorAll pe) document.querySelectorAll("li").forEach(item => { console.log(item.textContent); }); // Array se bhi kar sakte ho let items = Array.from(ul.children); items.forEach(item => { item.style.color = "orange"; });

Advanced DOM

Real projects mein kaam aane wali techniques

🎯 Event Delegation — Ek Handler, Hazaaron Elements! Advanced

💡
Har element pe alag-alag listener lagane ki zaroorat nahi! Parent pe ek listener lagao aur bubbling se saare children handle karo. Ye performance ke liye best hai!
// Problem: 100 buttons hain, 100 listeners?? Nahi! // Solution: Parent pe ek listener! document.querySelector("#list") .addEventListener("click", (e) => { // Check karo click kaun se element pe hua if (e.target.matches("li")) { console.log("Li click hua:", e.target.textContent); } // Dataset se ID le sakte ho if (e.target.dataset.id) { console.log("ID:", e.target.dataset.id); } });

🔭 MutationObserver — DOM Changes Ko Watch Karo Pro Level

// Jab DOM change ho, automatically pata chale let observer = new MutationObserver(function(mutations) { mutations.forEach(mutation => { console.log("DOM change hua!", mutation.type); }); }); // Kya observe karna hai batao observer.observe(document.body, { childList: true, // Children add/remove hone pe attributes: true, // Attributes change pe subtree: true // Andar ke sab changes pe }); observer.disconnect(); // Band karo

📐 Element Size aur Position Advanced

let el = document.querySelector(".box"); // Size (with padding, without border) el.clientWidth / el.clientHeight // Size (with padding + border) el.offsetWidth / el.offsetHeight // Position relative to parent el.offsetLeft / el.offsetTop // Exact position on screen let rect = el.getBoundingClientRect(); console.log(rect.top, rect.left, rect.width, rect.height); // Scroll position window.scrollX // Horizontal scroll window.scrollY // Vertical scroll el.scrollIntoView({ behavior: "smooth" }); // Smooth scroll to

⚡ DocumentFragment — Batch Insert Performance

// Bahut saare elements add karne ho toh: // BAD: Har baar DOM reflow hoga for(let i=0; i<100; i++) { document.body.appendChild(document.createElement("div")); } // GOOD: Pehle fragment mein, phir ek baar add karo let frag = document.createDocumentFragment(); for(let i=0; i<100; i++) { frag.appendChild(document.createElement("div")); } document.body.appendChild(frag); // Sirf 1 baar DOM touch!
